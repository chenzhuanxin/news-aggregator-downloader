# 新闻资讯下载器（News Aggregator Downloader）

一款本地运行的**多站点新闻聚合下载工具**：勾选新闻站点 → 选择「今天 / 前一天」→ 一键抓取新闻的**正文文字 + 新闻图片 + 视频链接**，并自动打包为 **Word (.docx)**（可选 PDF），按日期自动归类保存。全部在本机运行，无需联网服务。

采用 **Python (Flask) + HTML/JS** 构建，带漂亮的 Web 界面，支持单站点或全部 15 类站点勾选、并发抓取、实时进度显示。

---

## ✨ 功能特性

- **15 类新闻站点**聚合抓取：湖北日报（热推/通城/要闻）、观察者网、金十数据、澎湃新闻、腾讯新闻（国际/要闻）、网易（国际/国内/军事）、新华网（国际/湖北/即时）、云上通城
- **文字 + 新闻图片 + 视频链接**全量收录，图片随文嵌入 Word，视频以「【视频】链接」列出
- **今天 / 前一天**可选，保存目录下自动建子文件夹：`新闻资讯 20261009`（当天）、`新闻资讯 20261007`（前一天）
- **单站点**保存为「站点名 + 日期.docx」；**全部站点**每个站点一个文件、按日期归档
- **保存目录可自由选择**（弹窗浏览或直接输入路径）
- **并发抓取**（默认 4 线程，可在 `app.py` 顶部调整），全量 15 站约 2~6 分钟
- **实时进度**面板：每站点状态（等待/抓取中/成功/失败/无内容）+ 整体进度条 + 用时
- **可中途停止**，下载完成自动填充保存目录并可直接「打开」
- 单文件 **exe**，免安装、免 Python 环境（Release 提供）

## 🚀 快速开始（推荐：直接用 exe）

> 直接到 **GitHub Release** 页面下载 `新闻资讯下载器.exe`（Windows 单文件版），双击即可运行，**无需安装 Python 和任何依赖**。

1. 双击 `新闻资讯下载器.exe`，稍候浏览器自动打开界面（地址形如 `http://127.0.0.1:18763`）；
2. 勾选要下载的新闻站点（或点「全选」）；
3. 勾选日期：**今天** / **前一天**（可同时勾）；
4. 选择或直接输入**保存目录**；
5. 选择输出格式：**Word (.docx)** 或 **PDF**（PDF 需本机安装 LibreOffice，未装则自动回退 docx）；
6. 点击 **「一键下载」**，右侧实时显示每站点进度；
7. 完成后到你选择的目录下 `新闻资讯 日期\` 文件夹里查看 docx。

> **关于 Chrome**：腾讯国际/要闻两个站点需要浏览器环境抓取（Selenium）。若本机**已安装 Chrome**，无需任何额外操作；若未安装，请安装 [Google Chrome](https://www.google.com/chrome/) 后重试即可（其它站点无需 Chrome）。

## 🔧 从源码运行（开发者）

### 1. 环境要求
- Python 3.9+（推荐 3.11+）
- Chrome（可选，仅腾讯站需要）
- LibreOffice（可选，仅输出 PDF 时需要）

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 启动

```bash
python app.py
```

启动后程序自动打开浏览器；若未自动打开，手动访问 **http://127.0.0.1:18763**。

> **端口说明**：默认端口 **18763**（不常用，降低被占用概率）。若被占用会自动切换到下一个空闲端口，以启动日志里显示的地址为准。程序为**单实例**，重复双击会提示「程序已在运行」。

### 4. 运行方式

- **Windows**：可直接双击 `一键启动.bat`；
- **任意平台**：`python app.py`，然后在浏览器操作界面。

## 📦 打包成 exe（开发者）

在项目根目录执行（Windows）：

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name "新闻资讯下载器" \
  --icon "app_icon.ico" \
  --add-data "templates;templates" --add-data "static;static" \
  --collect-all selenium app.py
```

生成的单文件 exe 位于 `dist\新闻资讯下载器.exe`。

> 说明：`--collect-all selenium` 是必要的，否则打包后腾讯站会报 `No module named 'selenium.webdriver.chrome.webdriver'`。

## ❓ 常见问题（FAQ）

**Q：点击「一键下载」没反应？**
若打开的是旧页面，请按 `Ctrl + F5` 强制刷新（浏览器可能缓存了旧 JS）。仍无效请检查右下角进度区是否有提示（如「请先选择保存目录」）。

**Q：端口被占用怎么办？**
无需手动处理——程序会自动切换到下一个空闲端口，并以实际地址打开浏览器。若提示「程序已在运行」，说明已有实例在跑，直接使用即可，不要重复双击。

**Q：下载很慢？**
全量 15 站涉及较多图片，首次约需 2~6 分钟（视网络）。可在 `app.py` 顶部调整 `MAX_WORKERS`（1~8）提升并发，但过高易被目标站点限速。

**Q：PDF 格式为什么生成的是 docx？**
PDF 依赖本机安装 [LibreOffice](https://www.libreoffice.org/)，未安装时程序会自动回退为 docx。

**Q：需要联网 / 服务器吗？**
不需要。程序完全在本机运行，仅抓取各新闻站点公开页面。
